# Youtube-Shorts-Blocker-Python
Simple Selenium shorts blocker that rewinds the YouTube page when "/shorts/" is detected.
Table of Contents

General Info
This is a uni assignment for a design course.

Technologies Used
The coding environment used for this project is primarily through Python and the chrome web browser. To run this code, users must download 'selenium' through the following steps below.

Installing Selenium
NOTE: Be sure to not include the "" in the terminal
For Windows
1. Open command prompt
2. Paste the following: "pip install selenium"
   
For Mac
1. Open Terminal
2. Paste the following: "pip3 install selenium"

Features
- Opens chrome web driver
- Redirects shorts URL to previous page.
